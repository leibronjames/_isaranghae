# DREI Garden Deluxe

A responsive pixel planting browser game built with HTML, CSS, and JavaScript.

## Open the game

Open `index.html` in a browser. For best results, use VS Code Live Server.

## Features

- 4×4 interactive garden
- Plant, water, harvest, inspect, shop, and next-day tools
- Tomato, carrot, sunflower, and pumpkin growth stages
- Farmer movement and action animations
- Dirt, water, leaf, crop, and coin feedback effects
- Plot inspector with growth details
- Day/night transition and changing weather
- Rain that waters crops automatically
- Guided first-time tutorial
- Mobile bottom toolbar and plot information sheet
- Automatic localStorage save
- Sound effects generated in-browser
