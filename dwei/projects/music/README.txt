DREI MUSIC V2

FILES
- index.html
- style.css
- script.js

INSTALLATION
1. Extract the ZIP.
2. Put the whole "music" folder inside your "projects" folder.
3. Your project card should link to:

   href="music/index.html"

RECOMMENDED STRUCTURE

projects/
├── projects.html
└── music/
    ├── index.html
    ├── style.css
    └── script.js

GITHUB PAGES
This project is designed to work on GitHub Pages.

Important:
- Keep filenames lowercase.
- Upload all three files.
- Do not change the folder name unless you update your card link.
- The app requires internet access because it uses the Deezer catalog.
- Some tracks do not provide a preview. The app displays a message when that happens.

FEATURES
- Deezer music search
- Available 30-second previews
- Favorites
- Playlist creation
- Recently played
- Listening statistics
- Search history
- Dark/light theme
- Responsive mobile sidebar
- Sticky music player
- Previous/next controls
- LocalStorage saving
